# CV Web — Karen Viviana Jimenez

Portafolio profesional estático pensado para GitHub Pages.

## Antes de publicar
1. Cambiar `TU-USUARIO` por el usuario real de GitHub.
2. Cambiar `TU-CORREO@ejemplo.com` por el correo profesional que quieras publicar.
3. Colocar el PDF real en `assets/CV-Karen-Jimenez.pdf`.
4. Revisar y ajustar fechas, cargos y logros con el CV formal.
5. Crear un repositorio llamado `USUARIO.github.io` y subir estos archivos.

GitHub Pages puede publicar el sitio directamente desde un repositorio y usar una URL `usuario.github.io`.
